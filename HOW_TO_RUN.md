# 🚀 How to Run Save the Sea App

## Quick Setup (3 Steps)

### 1. Install Node.js
- Download from [nodejs.org](https://nodejs.org/)
- Install the latest version

### 2. Install Dependencies
```bash
# Open terminal in project folder
npm install
```

### 3. Run the App
```bash
npm run dev
```

## View the App
- Open browser and go to: `http://localhost:8080`
- The app will show in an iPhone mockup

## How to Use

### Navigation
- Click bottom tabs: Home, Learn, Impact, Community, Profile
- Active tab shows in blue

### Key Features
- **Home**: Virtual pet (Marina), daily challenges, quick actions
- **Learn**: Swipe through ocean facts and education
- **Impact**: View your environmental contributions
- **Community**: See leaderboard and events
- **Profile**: Check your stats and badges

### Mobile Experience
- Optimized for mobile viewing
- Touch and swipe naturally
- iPhone 14 Pro design

## Troubleshooting

**Port busy?**
```bash
npm run dev -- --port 3000
```

**Dependencies issues?**
```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```
